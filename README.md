# Pep Talk Press

A single-page encouragement dispenser. Pick a mood, press for a message,
copy one for a friend.

- **No dependencies, no build step.** One `index.html`, fonts from Google Fonts.
- **Music is synthesised in the browser** with the Web Audio API — there is no
  audio file. Off by default.
- **Portraits are public-domain files from Wikimedia Commons**, embedded as
  base64 so the page works offline. Licenses were checked via the MediaWiki
  API; only files tagged public domain were included.

Every historical fact on the co-signer slips is true. The framing is the joke;
the history is not.
